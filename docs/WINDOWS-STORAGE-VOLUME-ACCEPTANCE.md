# Windows 存储卷验收

## 前置条件

- 以实际 Windows 服务账号启动服务；该账号对 A、B、C 目录或 UNC 共享具有读写权限。
- 在存储卷管理页分别纳管 A、B、C；确认每个根目录含 `.yigongbao-volume.json`，且卷编码不同。
- A 设为 `HOT + ACTIVE`，B、C 设为 `HOT + STANDBY`；冷盘验收时将 A 转为 `COLD + READ_ONLY`。

## A/B/C 验收步骤

1. 在 A 创建订单备份，记录 ZIP 的卷编码、相对键和 SHA-256。
2. 将 B 设为 ACTIVE；确认 A 自动为 READ_ONLY，新订单写入 B，且 A 的订单仍可下载。
3. 在 A、B 写入同名相对键，确认两个文件内容独立。
4. 将 A 转为 COLD 后断开挂载；订单页必须保留记录、显示卷离线，并禁用下载/恢复。
5. 以不同盘符或 UNC 路径重新挂载 A，执行“确认挂载”；必须由标记文件和卷身份匹配原 A。
6. 不导入、不复制 ZIP，直接发起线上恢复；恢复任务必须固定 A 的卷 ID、相对键和 SHA-256。
7. 开启自动切换，令 B 达到阈值或不可达；只能切至已纳管 C，未纳管介质或 COLD 卷不得被选中。

## 迁移与回滚

在生产迁移前完成数据库完整备份。执行迁移后核对历史订单包、补传文件均关联 `legacy-hot` 卷；抽样下载和恢复。验收未通过时从数据库备份恢复，保留旧目录与文件，不删除历史卷标记。

## UNC 检查

使用服务账号验证 `\\host\share\path` 的创建、读取、原子移动、容量探测和断连恢复；不要使用仅交互式用户可见的映射盘符。
