# Production Account Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use executing-plans and test-driven-development task-by-task.

**Goal:** 将线上医工宝账号可靠地增量同步到本地备份系统，并提供可观测、可恢复、可手动触发的生产级能力。

**Architecture:** 线上接口以 RFC 3339 UTC 时间与 ID 组成稳定游标，并返回包含逻辑删除的变更事件。本地每页在同一事务内合并账号并推进 `bk_sync_cursor`，调度器与管理员手动触发共用一个互斥同步协调器；失败保留最后成功游标和可查询状态。

**Tech Stack:** Java 21、Spring Boot 3.2、MyBatis-Plus、MySQL 8、Vue 3、Element Plus、JUnit 5。

**Spec:** 本对话上一轮《账号同步模块审查结论》与既有需求分析文档。

## Global Constraints

- HTTP 可用，但内部账号接口必须支持现有 HMAC/Bearer 认证。
- 本地密码和启停状态首次建档后不被线上覆盖，本地变更不回写线上。
- 同步失败不得回退或越过最后成功游标。
- 禁止 XML Mapper；新增类、方法和关键逻辑必须有注释与关键日志。
- 数据库初始化脚本、升级脚本和一体化初始化脚本必须同步更新。

## Review Focus

- 超过一页时，UTC 游标能否被下一请求正确解析。
- 中间页失败时，是否从最后成功页恢复且不误报成功。
- 线上逻辑删除账号是否作为事件返回，但不覆盖已有本地启停决定。
- 旧响应或重复页是否会使来源资料倒退。
- 多次调度或手动触发是否会并发执行同一同步。
