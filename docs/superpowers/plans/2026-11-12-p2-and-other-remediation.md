# P2 及其他遗留问题实施计划

**设计依据：** `docs/superpowers/plans/2026-11-12-p2-and-other-remediation-design.md`

**约束：** 保留当前工作区全部 P1 改动；不修改首次登录管理员密码策略；本轮不执行 Git 提交，待用户明确要求时按仓库提交规范一次性提交。

## Task 1：状态机与数据正确性

1. 为过期空间预留重试、清理 `PARTIAL`、恢复 `SKIPPED_DELETED` 编写失败测试。
2. 实现容量池锁内过期、清理终态判断和显式恢复结果。
3. 运行相关后端测试。

## Task 2：竞争失败备份包可靠清理

1. 为 `STATE_CONFLICT` 清理登记、幂等删除、失败重试编写失败测试。
2. 扩展暂存表清理状态，新增定时清理服务与迁移。
3. 运行备份暂存与处理器测试。

## Task 3：外部 URL 与登录安全边界

1. 为内网/非允许主机/非法端口 URL 及登录限流编写失败测试。
2. 实现外部 URI 策略与数据库登录限流桶。
3. 更新配置样例、迁移和初始化脚本，运行安全相关测试。

## Task 4：审计归因与覆盖

1. 为账号、配置、下载、任务取消/重试的审计上下文编写失败测试。
2. 增加统一操作者上下文并补齐敏感操作审计。
3. 运行控制器与审计测试。

## Task 5：并发约束和响应契约

1. 为跨配置并发校验、管理员离线冷备卷、离线下载失败信封编写失败测试。
2. 实现事务内配置投影校验、巡检状态限制与失败信封。
3. 运行配置、存储卷、下载接口测试。

## Task 6：查询正确性与性能

1. 为组合订单筛选、调度批量查询、封存分页、审计游标分页编写失败测试。
2. 实现统一动态 SQL、批量调度查询、数据库分页/聚合与受控审计导出。
3. 运行 mapper/service/controller 测试。

## Task 7：前端异步一致性和流式下载

1. 为恢复详情/订单/账号旧响应、补传 401 Promise、下载路径编写失败测试。
2. 实现请求代次保护、XHR reject 和单次下载票据流程。
3. 运行前端测试和生产构建。

## Task 8：精确对象版本删除许可

1. 为版本不一致和缺失版本许可编写失败测试。
2. 扩展 permit 协议及校验，保持冻结集合不可变。
3. 运行清理相关测试并更新协议文档。

## Task 9：集成演练入口与全量验证

1. 增加真实 MySQL 多实例、Windows 存储、NAS/COS 的 opt-in 测试配置/演练说明与负载入口。
2. 运行后端全套测试、前端全套测试、前端生产构建和差异检查。
3. 对照遗留清单逐项复核并完成最终自审。

## Review Focus

- 数据删除是否仍可能越权、越版本或在状态未知时执行。
- 新增票据、限流和清理状态是否具备多实例原子性。
- 失败响应是否仍可能被包装成成功信封。
- 分页排序是否稳定，筛选条件是否全部取交集。
- 前端关闭/切换页面后旧请求是否仍可写回状态。
