# 订单备份任务详情重设计

## 1. 目标

将“订单备份”页当前嵌在任务列表下方的详情区域，改造成独立、可聚焦、适合大数据量浏览的详情工作区；同时把任务文件明细改为服务端分页，避免大任务一次返回全部文件以及轮询期间重复加载全量文件。

## 2. 已确认的交互方案

- 点击任务列表“详情”后，打开接近全屏的 Element Plus `Dialog`；桌面端约 `96vw × 94vh`，小屏进入全屏模式。
- 弹窗顶部固定显示任务编号、状态、进度、执行结果、容量、存储卷及可用操作；正文滚动时保持任务上下文可见。
- 正文使用三个页签：`订单明细`（默认）、`文件明细`、`执行日志`。
- 订单明细继续服务端分页，但不再用表格展开行塞入完整业务快照。点击订单“详情”打开右侧抽屉。
- 订单抽屉按“基础信息、存储信息、文件明细、执行日志、业务快照”组织；业务快照默认折叠，降级备份操作仅在服务端判定有资格时显示于抽屉底部。
- 文件明细页签首次进入时才加载数据；翻页、改变每页条数时只请求当前页。
- 执行日志页签首次进入时加载任务日志；订单抽屉内日志加载指定订单日志，不再叠加第二层日志弹窗。
- 关闭任务详情时停止详情轮询并清理抽屉/页签临时状态；任务列表的页码与滚动位置不受影响。

## 3. 文件分页接口

沿用现有路径并升级返回结构：

```http
GET /api/v1/admin/jobs/{jobId}/files?current=1&size=20&sourceOrderId={optional}
```

响应 `data`：

```json
{
  "records": [],
  "total": 0,
  "current": 1,
  "size": 20,
  "pages": 0
}
```

约束：

- `current >= 1`，`1 <= size <= 100`，非法参数由服务端拒绝。
- 始终按 `bk_job_file.id ASC` 稳定排序。
- 必须按 `job_id` 过滤；传入 `sourceOrderId` 时再按 `source_order_id` 过滤，供订单抽屉复用。
- 当前存储卷状态只为本页记录批量投影，不能再为整个任务加载全部文件。
- 本次前后端同步升级，不保留旧的“数组响应”兼容分支，避免一个接口出现两种响应形态。

## 4. 前端数据流

任务详情数据拆成互不绑死的加载单元：

- `loadJobSummary`：任务头部和进度。
- `loadJobOrders`：当前订单页。
- `loadJobFiles`：任务文件当前页，仅文件页签激活后调用。
- `loadOrderFiles`：订单抽屉文件当前页，携带 `sourceOrderId`。
- `loadTaskLogs` / `loadOrderLogs`：任务、订单日志使用独立分页状态，互不覆盖。

运行中任务保持 3 秒轮询，但轮询只刷新任务摘要和当前订单页；不得自动重置页码，也不得反复请求文件页和日志页。用户主动翻页时只更新对应数据集。

## 5. 组件边界

- `JobDetail.vue`：任务详情 Dialog 外壳、固定摘要、页签及任务级操作。
- `JobOrderDetailDrawer.vue`：订单详情 Drawer、订单级操作及分区。
- `JobFileTable.vue`：任务文件和订单文件共用的表格及分页展示。
- `ExecutionLogPanel.vue`：任务和订单共用的日志列表及分页展示。
- `useBackupConsole.js`：可见性、选中项、分页、懒加载、轮询生命周期和 API 调用。

## 6. 状态与失败处理

- 切换任务时，任务文件、订单抽屉文件和日志页码重置为第一页，旧请求结果不能覆盖新任务状态。
- 接口失败保留弹窗及当前已加载内容，并显示现有全局错误通知；分页控件不得误报总数。
- 任务被删除时，停止轮询并关闭任务详情及订单抽屉，提示任务已不存在。
- 终态任务加载完成后立即停止详情轮询。
- 关闭任务详情后，即使未完成请求随后返回，也不得重新打开或污染下次详情。

## 7. 非目标

- 不改变备份任务创建、自动备份、失败重试和降级备份的业务规则。
- 不改变任务文件表结构，也不引入游标分页；当前后台管理场景使用稳定 ID 排序的页码分页。
- 不修改线上医工宝系统接口。
- 不在本次改造中重做任务列表或订单文件主页面。

## 8. 验收标准

- 任务详情不再占据任务列表页面下半部。
- 任务、订单、文件和日志信息可在弹窗/抽屉层级内完整浏览，且不存在嵌套日志弹窗。
- 打开任务详情默认不请求文件接口；首次打开文件页签只请求一页。
- 文件接口在任务级和订单级查询下均返回正确分页元数据，单次最大 100 条。
- 运行中任务轮询不触发文件或日志接口，不改变用户当前页。
- 前后端定向测试、完整测试及前端生产构建通过。
